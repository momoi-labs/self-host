# Changesets

Run `npm run changeset` from the repository root for each user-visible change.
Write the release note in English and commit it with the change.

Changesets updates the version PR on `main`. Merging that PR publishes the
GitHub packages and the Homebrew update. See [Releases](../docs/releases.md)
for the initial registry setup, the first `v0.4.0` release, and retries.

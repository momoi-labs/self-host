# Implementação em Rust

A Plataforma (CLI + daemon) será escrita em **Rust**, alinhada ao objetivo de aprendizado do Operador e ao desenho daemon + gRPC (`tonic`) falando com a Docker Engine API. Go e TypeScript foram alternativas práticas (ecossistema Docker / proximidade com Disco·Dokploy) e ficaram de lado de propósito.

**Status:** accepted

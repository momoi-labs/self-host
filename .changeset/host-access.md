The console has a Host page. It opens a login shell on the Host, as the account the Platform runs under, and on a Mac it opens the screen through Screen Sharing in a window of its own, for the dialogs that only take a click. Both are off until the Operator turns them on in Settings > Host, and the page leaves the menu while both are off. On a Linux Host that runs the Platform as root, the shell is a root shell.

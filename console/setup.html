Instructions

Point your device's DNS resolver to the Host IP so that *.home.lan resolves locally.

macOS
  1. Open System Settings → Network.
  2. Open the active connection and select DNS.
  3. Add the Host IP as a DNS server, then apply the change.
Linux

With systemd-resolved:

sudo resolvectl dns INTERFACE HOST_IP
sudo resolvectl domain INTERFACE ~SUFFIX

Replace INTERFACE, HOST_IP and SUFFIX with the values for your host.

Windows
  1. Open Network Connections and the active adapter's properties.
  2. Open Internet Protocol Version 4 (TCP/IPv4).
  3. Use the Host IP as the preferred DNS server and save.
iOS and Android

Edit the active Wi-Fi network, choose manual or static DNS, and use the Host IP as the first DNS server.
